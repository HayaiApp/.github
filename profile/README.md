# Hayai

Hayai is an open-source Android manga and light-novel reader built directly on TachiyomiJ2K.

- [Hayai](https://github.com/HayaiApp/hayai): source, documentation, issue tracker, and development status
- [Development nightlies](https://github.com/HayaiApp/hayai-nightly/releases): automated builds from `master`
- [Wiki](https://github.com/HayaiApp/hayai/wiki): installation, migration, extensions, novel reading, E-Hentai, and troubleshooting

The current reset is under active development. No reset-era stable release has been published yet.

Hayai retains J2K as its architectural parent, ports adult-source behavior from TachiyomiSY, and ports novel-reader behavior from Tsundoku. LNReader provides the JavaScript plugin ecosystem.
